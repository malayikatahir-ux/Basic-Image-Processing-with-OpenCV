# Basic-Image-Processing-with-OpenCV
This repository contains my first Computer Vision lab work using Python and OpenCV.

The lab focuses on basic image processing operations, including image loading, shape inspection, resizing, cropping, clockwise and anticlockwise rotation, grayscale conversion, RGB and HSV color space conversion, and saving the processed images.

This task helped me build a practical understanding of how images can be loaded, transformed, and represented using Python and OpenCV.
