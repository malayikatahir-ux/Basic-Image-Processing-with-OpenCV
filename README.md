# Computer Vision Lab 01: Basic Image Processing with Python & OpenCV

This repository contains my first **Computer Vision Lab** project, focused on understanding the fundamentals of image processing using **Python and OpenCV**.

## Lab Overview

The lab explores how digital images can be loaded, inspected, transformed, converted between different color spaces, and saved using Python-based computer vision techniques.

### Operations Covered
 
* Loading and displaying images
* Inspecting image shape and dimensions
* Resizing images
* Cropping specific regions
* Clockwise rotation
* Anticlockwise rotation
* Grayscale conversion
* RGB color space representation
* HSV color space conversion
* Saving processed images

## Technologies Used

* **Python**
* **OpenCV (cv2)**
* **NumPy**

## Learning Outcomes

Through this lab, I developed a practical understanding of how images are represented as numerical data and how OpenCV can be used to manipulate and analyze them.

This hands-on work helped me understand the connection between basic Python programming and real-world **Computer Vision** tasks, while building a foundation for more advanced image processing and vision techniques.
